# GraphTrack

GraphTrack is an intelligent, knowledge graph-based assistant for software project management. It unifies scattered tasks, dependencies, developer activity, and source code into a single system to easily detect workflow bottlenecks and identify domain experts.

### Core Features
* **Unified Knowledge Graph:** Connects project tasks, GitHub commits, and issues using FalkorDB.
* **Bottleneck Detection:** Identifies critical paths and blocking tasks using graph algorithms.
* **Expert Discovery:** Recommends the right contributors based on historical repository data.

**Tech Stack:** Python, FastAPI, FalkorDB, and GitHub APIs.
